# 🎮 PartyFind

PartyFind is a social platform for gamers to find teammates, friends and communities across different multiplayer games.

## ✨ Features

- 👤 Player Profiles
- 🔍 Search Players
- 🎮 Multi-game Support
- 💬 Private Chat *(coming soon)*
- 👥 Friends System *(coming soon)*
- 🎯 Party Invitations *(coming soon)*
