# 🏠 Homepage

## Назначение

Главная страница PartyFind — это первое, что видит пользователь.

Она должна быстро объяснить:

- Что такое PartyFind
- Для кого он создан
- Какие преимущества предлагает
- Побудить пользователя зарегистрироваться

---

```
Navbar
│
├── Hero

├── Popular Games
│
├── Features

├── Statistics

├── CTA
│
└── Footer
```

# Hero

### Цель

Главный экран должен сразу объяснить идею проекта.

Содержит:

- Badge
- Большой заголовок
- Подзаголовок
- Две CTA-кнопки
- Статистику проекта
